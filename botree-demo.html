Risk Mitigations

Merge Conflicts in main.py

All 3 teams touch main.py. Mitigate by defining clear route ownership and merging in strict order.

ChromaDB Schema Changes

Team 2 changes may break Team 3's cleanup scripts. Sync on collection schema before Phase 2.

Frontend State Management

Auth state affects all components. Team 1 delivers auth context first, others consume it.

API Contract Changes

Backend route changes break frontend. Lock API contracts at kickoff, version breaking changes.
