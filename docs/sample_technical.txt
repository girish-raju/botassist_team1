BotAssist Architecture Overview

BotAssist uses a Retrieval-Augmented Generation (RAG) pipeline to enable natural language queries over uploaded documents. When a user uploads a document, the backend splits it into overlapping chunks of approximately 500 tokens each. Each chunk is passed through an embedding model to generate a dense vector representation, which is then stored in ChromaDB along with metadata (document ID, chunk index, source filename). The ChromaDB collection is persisted to disk so embeddings survive server restarts. At query time, the user's question is embedded using the same model, and ChromaDB performs a cosine similarity search to retrieve the top 5 most relevant chunks.

The backend is built on FastAPI (Python 3.12) and exposes a RESTful API for authentication, document management, chat, and search. SQLite stores user accounts, document metadata, and chat history. The frontend is a single-page React 18 application bundled with Vite. It provides a chat interface where users can select a document context, type questions, and receive answers with source citations. The React app communicates with the backend via fetch calls to the /api/ endpoints, using JWT tokens for authentication. The entire stack runs locally for development, with ChromaDB and SQLite requiring no external database servers.
