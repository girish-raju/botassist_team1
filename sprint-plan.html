1 Project Overview

Understand what you're building, where you're starting, and what success looks like.

What You're Building

A RAG-powered documentation chatbot. Users upload technical docs, ask questions, and get AI-generated answers with source citations. Think of it as an internal knowledge base assistant.

What You Start With

A base repository with partial implementation — FastAPI backend, React frontend, SQLite database, ChromaDB vector store. Core RAG works (upload, chunk, search, answer) but has bugs, no auth, basic UI, and no tests.

What You Deliver

A clean, working application with authentication, public/private pages, polished chat UI, proper RAG pipeline, and optionally AI-generated help docs. Quality over quantity — a smaller feature set that works perfectly beats a larger one that's broken.

7 Rules & Guidelines

Follow these throughout the day to stay on track.

  • Use Claude Code as your AI assistant — it can help with code, debugging, and planning
  • Commit early, commit often — use conventional commits (feat, fix, refactor)
  • Branch naming: team-{N}/{feature-name}
  • All secrets must be in environment variables, never hardcoded
  • LLM choice is yours — Claude, GPT, Gemini, Llama, or any other
  • Do NOT copy code from other teams
  • Ask questions! The facilitator is here to help unblock you
  • Quality over quantity — a working login + chat is better than a broken everything
